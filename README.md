# Plateau Hotels 

A modern hotel booking web application designed to provide a seamless and intuitive experience for users searching for and reserving hotel accommodations.

## 🔗 Live Demo
https://plateau-hotels.vercel.app/

## 📸 Screenshots

##  Features

- Browse available hotels with detailed information
- Responsive and modern UI design
- Booking interface with user-friendly flow
- Price display and hotel details
- Interactive components with smooth transitions

##  Tech Stack

- React
- Tailwind CSS
- JavaScript (ES6+)
- Supabase(db)
- Vercel (Deployment)

##  Project Overview

This project was built to simulate a real-world hotel booking platform, focusing on clean UI/UX design and component-based architecture. It demonstrates the ability to build scalable frontend applications with modern tools and best practices.

## What I Focused On

- Clean and structured UI design
- Reusable component architecture
- Responsive design across devices
- Smooth user interactions

## ⚠️ Note

This is a frontend-focused MVP. Booking functionality is simulated and does not process real transactions.
